# เครื่องมือโครงงาน ว.2

เว็บสำหรับนักเรียนใช้เอง ตามคู่มือการเขียนเล่มโครงงาน ฉบับปรับปรุง 1/2566

| ไฟล์ | ใช้ทำอะไร |
|---|---|
| `index.html` | หน้าแรก ลิงก์ไปเครื่องมือทั้งสอง |
| `check.html` | ตรวจเล่ม ว.2 (.docx / .pdf) และบันทึกผลตรวจเป็น PDF |
| `poster.html` | ทำโปสเตอร์ 60×90 ซม. ส่งออก PDF / PNG |

ทุกไฟล์ทำงานในเบราว์เซอร์ทั้งหมด ไฟล์ของนักเรียนไม่ถูกส่งออกจากเครื่อง
(ตรวจ .pdf ต้องต่ออินเทอร์เน็ตเพื่อโหลด pdf.js จาก cdnjs)

ไฟล์ในโฟลเดอร์นี้สร้างจาก `node app_v2check/build.mjs` และ `node app_poster/build.mjs` ห้ามแก้ตรงนี้โดยตรง
